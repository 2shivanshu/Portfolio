# Shivanshu Srivastava - Portfolio

This is the personal portfolio website of Shivanshu Srivastava.

## Project info

A digital showcase of my work, skills, and projects.

## Technologies

This project is built with:

- Vite
- TypeScript
- React
- shadcn-ui
- Tailwind CSS

## Development

To run this project locally:

1. Clone the repository
2. Install dependencies:
   ```sh
   npm install
   ```
3. Start the development server:
   ```sh
   npm run dev
   ```

## Deployment

This project is configured for deployment on Netlify.
The build command is `npm run build` and the publish directory is `dist`.
